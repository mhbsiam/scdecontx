# Benchmark tables

Generated by `scripts/report.py` from `results/results.json`. Values are mean ± SD over datasets (seeds) unless marked; n is the number of datasets. MAE is the mean absolute error of per-cell contamination against the simulated truth. The lowest value in each row is bold. scdecontx runs celda's algorithm, so its estimates equal R's from the same start; its rows differ from R's only through the random initial values. See `README.md` for the design.
